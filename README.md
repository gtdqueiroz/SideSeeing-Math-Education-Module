# SideSeeing Mathematics Education Module

An exploratory module for connecting mathematical concepts to multimodal
trajectory data collected with smartphones.

## Project scope

The project investigates how video, audio, accelerometer, and GPS signals can
represent the same geometric trajectory. Its initial activities focus on planar
figures such as line segments, circles, and simple polygons.

## Current stage

The current work focuses on defining a collection protocol and an initial
learning activity. Python tools for processing and visualization will be added
after the first trajectories are organized.

## Repository policy

This repository does not include raw videos, audio recordings, GPS traces, or
participant-identifying data.
